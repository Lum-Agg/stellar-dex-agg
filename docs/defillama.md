# DefiLlama Listing

LumAgg is listed as a DEX aggregator on DefiLlama. The listing reports LumAgg's
entry notional volume from the public analytics API; it is not TVL and does not
use hop-weighted routed volume.

- [LumAgg on DefiLlama](https://defillama.com/dex-aggregators/chain/stellar)
- [LumAgg stats page](https://lumagg.xyz/stats)
- [Stats API](https://api.lumagg.xyz/api/v1/stats)
- [Adapter source and methodology](https://github.com/Lum-Agg/stellar-dex-agg/tree/main/integrations/defillama)

The upstream adapter was merged into [DefiLlama/dimension-adapters PR #8330](https://github.com/DefiLlama/dimension-adapters/pull/8330).
